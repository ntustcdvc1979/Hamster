# 🐹 尋找內心的倉鼠

用手機玩的真實地點尋寶遊戲，場地是台北市松山的永吉國中。主持人在地圖上放好四個物品，玩家打開網頁就能直接開始，拿著手機靠 GPS **依照順序**找出它們；每找到一個都有小任務，主持人確認完成後才能找下一個。

- **玩家**（`docs/index.html`，網站首頁）：打開就開始。畫面只顯示「離下一個寶物還有幾公尺」和鼠鼠嗅覺提示（依校園大小調整）。走進判定範圍後按「我找到了！」→ 出現該關的小任務 → 等主持人按完成 → 跳出「獲得意義」與「給自己的一句話」→ 繼續找下一個。點左上角名字可以改暱稱（主持人用名字幫你按完成）。
- **主持人**（`docs/host.html`）：
  - 「物品」分頁：選物品後點地圖放置或移動、拖曳圖釘、「📍 放我這」；按「✏️ 說明」可以修改物品名稱、小任務、獲得意義、給自己的一句話，玩家畫面即時更新。
  - 「🌻 出題」分頁：瓜子關的 12 格提示圖、開始作畫按鈕，以及玩家目前畫到第幾格。
  - 「玩家」分頁：列出正在做任務的玩家，按「✅ 完成」放行；同一關多人時可以按「全部完成」。

四關（順序固定，預設文字與圖示在 [docs/common.js](docs/common.js) 的 `ITEMS`）：

1. 靜音滾輪：小任務由主持人說明（可在主持人頁面編輯文字）
2. 柔軟紙棉：鼠鼠視角微距攝影，網頁有「📷 打開相機拍照」，拍好可全螢幕展示（照片只留在自己手機，不會上傳）
3. 飽滿的瓜子：12 格飽滿記憶大考驗（[docs/memory.js](docs/memory.js)）。主持人在「🌻 出題」分頁看著 12 格原圖口頭描述，按「開始作畫」後，正在瓜子任務的玩家手機同步倒數 3 秒、直接進入畫布，每格 3 秒；畫完出現作品牆，可切換「原圖對照」。12 格內容是固定陣列，每支手機都一樣
4. 蘋果木磨牙棒：小任務由主持人說明（可在主持人頁面編輯文字）

後端是 Firebase Realtime Database（即時同步），網站架在 GitHub Pages（GPS 一定要 https 才能用）。

## 玩法

1. 活動前，主持人到永吉國中現場，在「物品」分頁依序選物品，按「📍 放我這」放好四個位置（之間最好相隔 40 公尺以上），需要的話按「✏️ 說明」修改文字
2. 「設定」分頁調整判定範圍（建議 12–15 公尺），並按「清空所有玩家進度」把測試資料清掉
3. 按「玩家連結」讓玩家掃 QR code，玩家允許定位後就開始找第 1 個
4. 玩家完成小任務後，在「玩家」分頁按「✅ 完成」；有玩家在等時，「玩家」分頁標籤上會出現紅色數字

## 注意事項

- **GPS 誤差**：操場等空曠處約 5–10 公尺，靠近校舍會到 15–20 公尺。距離提示以校園大小設計：120 公尺以上「🐾 什麼味道都聞不到」、70「👃 聞到一點點味道」、40「🐹 鬍鬚動了動」、約 20「💨 香味撲鼻」、更近「💛 興奮到轉圈圈」。
- **iPhone**：Safari 要允許「定位服務」（設定 → 隱私權 → 定位服務 → Safari 網站 → 使用 App 期間）。
- **螢幕常亮**：玩家畫面會嘗試讓螢幕不自動關閉；鎖屏後 GPS 會暫停，回來會自動恢復。
- **安全性**：為了好上手，資料庫規則沒有登入機制，知道網址的人都能修改物品位置；懂技術的玩家也能從瀏覽器開發者工具看到地點座標。朋友間的活動通常沒問題，若要更嚴謹可以再加上 Firebase Authentication。
- 本機測試：`npx serve docs` 之後用 `http://localhost:3000` 開（localhost 可以用 GPS）。
